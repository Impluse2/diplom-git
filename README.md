# Nike Air Mag

Веб-сайт, посвящённый культовым кроссовкам Nike Air Mag из фильма "Назад в будущее 2".

## Описание проекта

Одностраничный сайт (landing page) с информацией о кроссовках Nike Air Mag:

- футуристический дизайн
- автоматическая шнуровка
- встроенная подсветка
- ограниченный выпуск

## Технологии

- HTML5
- CSS3
- JavaScript (ES6)
- Swiper.js (слайдер)
- FsLightbox (видео)
